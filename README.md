# GateFlow - Web Deployment Bundle

This folder contains the complete production-optimized Web application for GateFlow Virtual Lab.

## Quick Local Run:
To run this website locally on your computer:
```bash
python3 -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in any web browser.

## Deploying to Production:
You can directly drag & drop this entire folder into:
- **Firebase Hosting** (`firebase deploy --only hosting`)
- **Netlify** / **Vercel** / **GitHub Pages**
- Any standard static web server (Apache, Nginx, Cloudflare Pages).
